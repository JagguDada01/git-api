# GitHub Profile Lookup

A simple web app that fetches and displays public GitHub profile information by username.

## Features

- Search for any GitHub username
- Display avatar, name, bio, followers, following, and public repositories
- Show a helpful message when a user is not found
- Responsive dark-themed interface

## Getting started

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/JagguDada01/git-api.git
cd git-api
```

No build tools or dependencies are required. The app uses the public [GitHub REST API](https://docs.github.com/en/rest/users/users#get-a-user).

## Usage

1. Enter a GitHub username in the search field.
2. Select **Enter**.
3. View the user’s public profile details.

## Project files

- `index.html` — page structure
- `style.css` — responsive visual styling
- `app.js` — GitHub API request and profile rendering logic
